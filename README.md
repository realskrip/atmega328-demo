Сборка:
C:\avr\avrasm2\avrasm2.exe -fI blink.asm
	fI - создать Intel HEX файл
	
Прошивка:
C:\avr\avrdude\avrdude.exe -c usbasp -p m328p -U flash:w:blink.hex:i
	c - выбрать программатор
	p - выбрать микроконтроллер
	U - Выполни операцию с памятью микроконтроллера. -U <memory>:<operation>:<file>:<format>. :i - file имеет формат Intel HEX.

Схема подключения OLED SSD1306 к микроконтроллеру Atmega328p:
;oled pin        chip pin        what is
;GND             GND             power supply
;VCC             VCC             power supply
;D0              pin 19(PB5)     SCK(SPI)
;D1              pin 17(PB3)     MOSI(SPI)
;CS              pin 16(PB2)     chip select(SPI)
;RES             pin 14(PB0)     reset
;DC              pin 15(PB1)     command(0)/data(1)

Биты регистра SPSR:
	0
	1
	2
	3
	4

	6
	7 SPIF (SPI Interrupt Flag) Автоматически становится 1 в тот момент, когда все 8 бит байта регистра SPDR полностью ушли на линию.

Регистры:
DDRB	Определяет направление выводов порта B: 0 → вход, 1 → выход
PORTB	Управляет состоянием вывода: при DDRB=1 → 0 = LOW, 1 = HIGH
SPCR    SPI Control Register (вкл/выкл и настройка модуля SPI)
SPDR 	SPI Data Register через этот регистер отправляем и принимаем один байт
SPSR	SPI Status Register

Схема OLED:
OLED SSD1306 128 x 64 — структура памяти (GDDRAM)
==================================================

                      128 колонок (x = 0 .. 127)
        col:  0    1    2  ...  126  127
             +----+----+----+----+----+
page 0 (y=0..7)  |    |    |    |    |    |   <- страница 0
             +----+----+----+----+----+
page 1 (y=8..15) |    |    |    |    |    |   <- страница 1
             +----+----+----+----+----+
page 2 (y=16..23)|    |    |    |    |    |
             +----+----+----+----+----+
page 3 (y=24..31)|    |    |    |    |    |
             +----+----+----+----+----+
page 4 (y=32..39)|    |    |    |    |    |
             +----+----+----+----+----+
page 5 (y=40..47)|    |    |    |    |    |
             +----+----+----+----+----+
page 6 (y=48..55)|    |    |    |    |    |
             +----+----+----+----+----+
page 7 (y=56..63)|    |    |    |    |    |   <- страница 7
             +----+----+----+----+----+

  1 страница = полоса высотой 8 пикселей
  1 колонка внутри страницы = 1 байт = 8 пикселей по вертикали


Один байт (одна колонка одной страницы):
=========================================

  бит 7  ---  [ ]   <- нижний пиксель (y mod 8 = 7)
  бит 6  ---  [ ]
  бит 5  ---  [ ]
  бит 4  ---  [ ]
  бит 3  ---  [ ]
  бит 2  ---  [ ]
  бит 1  ---  [ ]
  бит 0  ---  [ ]   <- верхний пиксель (y mod 8 = 0)

  байт = 0b00000001  ->  горит только верхний пиксель
  байт = 0b10000000  ->  горит только нижний пиксель
  байт = 0b00000000  ->  все 8 пикселей погашены
  байт = 0b11111111  ->  все 8 пикселей включены


Перевод координат пикселя (x, y) в адрес памяти:
=================================================

  page   = y / 8      (целочисленное деление, 0..7)
  bit    = y mod 8     (остаток, 0..7)
  column = x           (0..127)

  адрес байта  = (page, column)
  номер бита   = bit


Порядок записи в горизонтальном режиме адресации (0x20, 0x00):
================================================================

  page 0: col 0 -> col 1 -> col 2 -> ... -> col 127 -\
                                                       |
  page 1: col 0 -> col 1 -> col 2 -> ... -> col 127 <-/
                                                       |
  page 2: col 0 -> ...                          и т.д. до page 7

  Итого: 8 страниц x 128 колонок = 1024 байта = весь экран
